# Portfolio — Koffi Franck Michael (version GitHub Pages, sans dossiers)

Tous les fichiers sont à la racine : aucun dossier à envoyer.

## Mise en ligne sur GitHub Pages

1. Décompresse le zip sur ton ordinateur (n'envoie pas le zip lui-même).
2. Dans ton dépôt `TON-PSEUDO.github.io` : Add file › Upload files › « choose your files ».
3. Sélectionne TOUS les fichiers d'un coup (Ctrl + A), puis Commit changes.
   Un fichier du même nom déjà présent est remplacé automatiquement.
4. Settings › Pages : branche `main`, dossier `/ (root)`, Save.
5. Ton site est en ligne après une à deux minutes sur `https://TON-PSEUDO.github.io`.

## Après la mise en ligne

- Liens GitHub et LinkedIn : dans `index.html`, cherche « Décommente ce bloc ».
- Aperçu de partage : remplace `./og-image.jpg` (balise og:image) par
  `https://TON-PSEUDO.github.io/og-image.jpg`.
